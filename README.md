# SPOC – Informatique

Dépôt GitHub regroupant le développement logiciel et la documentation
informatique du projet SPOC.

Le dépôt contient notamment les éléments liés à **ROS 2**, **micro-ROS**,
à l'**STM32**, à la **base de données**, à l'**IHM**, à la **simulation**
et aux **tests** du système.
